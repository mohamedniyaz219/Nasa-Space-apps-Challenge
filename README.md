# Space Dive 🚀

**NASA Space Apps Challenge Project**

An interactive web-based space exploration experience that takes you on a journey through our solar system. Space Dive combines immersive visuals, educational content, and interactive 3D rendering to create an engaging space exploration platform.

## ✨ Features

- **Immersive Landing Experience**: Video background with space-themed design
- **Interactive 3D Solar System**: Real-time 3D visualization of planets, asteroids, and celestial bodies using Three.js
- **Educational Content**: Detailed information about planets, asteroids, and comets
- **Near-Earth Object Visualization**: Toggle-able asteroid display with real NASA data integration
- **Responsive Design**: Works across different screen sizes and devices
- **Team Showcase**: Meet the talented team behind the project

## 🌟 Project Structure

```
project space dive/
├── index.html          # Main landing page
├── index3.html         # Space bodies information page
├── index4.html         # 3D Solar System experience
├── aboutus.html        # Team information page
├── styles.css          # Main stylesheet
└── bg-video.mp4        # Background video
```

## 🛠️ Technologies Used

- **HTML5** - Structure and semantic markup
- **CSS3** - Styling with modern features like flexbox and animations
- **JavaScript** - Interactive functionality
- **Three.js** - 3D graphics rendering for the solar system
- **OrbitControls** - Camera controls for 3D navigation

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Local web server (optional, for best experience)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/mohamedniyaz219/Nasa-Space-apps-Challenge.git
   cd Nasa-Space-apps-Challenge
   ```

2. **Navigate to the project directory**
   ```bash
   cd "project space dive"
   ```

3. **Open the project**
   
   **Option A: Direct file access**
   - Open `index.html` in your web browser
   
   **Option B: Local server (recommended)**
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Python 2
   python -m SimpleHTTPServer 8000
   
   # Using Node.js
   npx http-server
   ```
   
   Then navigate to `http://localhost:8000`

## 🎮 How to Use

1. **Start at the Landing Page** (`index.html`)
   - Experience the immersive space-themed interface
   - Navigate using the menu to explore different sections

2. **Explore the Solar System** (Experience → `index4.html`)
   - Use mouse controls to navigate the 3D space
   - Toggle asteroids on/off with the button
   - Observe planetary orbits and celestial bodies

3. **Learn About Space Bodies** (About Entity → `index3.html`)
   - Browse cards containing information about planets, asteroids, and comets
   - Hover over cards for interactive effects

4. **Meet the Team** (Team → `aboutus.html`)
   - Learn about the contributors and their roles
