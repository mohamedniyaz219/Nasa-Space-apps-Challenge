# Space Dive

Space Dive is a project for the NASA Space Apps Challenge. This web application aims to provide users with an interactive experience related to space exploration and NASA missions.

## Features
- Background video for immersive experience
- Multiple HTML pages (About Us, Home, etc.)
- Custom CSS styling

## Project Structure
```
project space dive/
├── aboutus.html
├── bg-video.mp4
├── index.html
├── index3.html
├── index4.html
├── styles.css
```

## Getting Started
1. Clone the repository.
2. Open `index.html` in your browser to start exploring.

## About
This project was created for the NASA Space Apps Challenge 2025 by the team Space Dive.
